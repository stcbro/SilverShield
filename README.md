# 银盾 SilverShield

一款基于安卓**无障碍服务**的广告/弹窗跳过工具，专为**保护老人**设计：自动点击广告本身提供的“跳过 / 关闭”按钮，并内置**规则自动更新**与**拦截统计**。

> 本应用只点击界面上“已存在”的按钮，不破解、不屏蔽、不删除广告，不收集任何隐私。它是对厂商违规广告的“民间补位”，治本仍要靠完善相关法规与厂商自律。

---

## 一、核心特性

| 特性 | 说明 |
|------|------|
| **自动跳过广告** | 基于无障碍服务，识别并点击开屏广告、应用内弹窗的“跳过 / 关闭”按钮；规则含 300+ 主流 App |
| **规则自动更新** | 启动即检查、后台每日定时从仓库拉取最新规则并自动合并，**无需手动复制粘贴**（从根上规避“长文本被手机剪贴板截断”） |
| **应用自动升级** | 联网时自动检测新版本并**静默下载**，提示一键安装；升级包须与已装版本**签名一致**（本项目各版本均为同一签名） |
| **大字引导 + 状态灯** | 引导页超大字体、绿色状态灯实时显示无障碍是否开启，可选**语音播报**使用说明 |
| **紧急保护** | 拨号 / 通话 / 相机 / 支付等界面**完全不触发跳过**，防止误触关闭重要弹窗 |
| **拦截统计** | 记录每次拦截（按 App 排行），可**一键分享给子女 / 家人** |
| **两层规则库** | A 层复用社区维护的主流规则；B 层为本项目手写的“老人专属”规则（清理类、现金奖励、短剧、监控等高频受害 App） |

## 二、工作原理

监听窗口变化 → 按当前 App 包名的 `hashCode` 查规则 → 执行 `popup_rules` 关闭应用内弹窗 → 用关键词在界面寻找“跳过 / 关闭”按钮自动点击。规则 key 采用与 Java 完全一致的 `String.hashCode()`。

## 三、安装与编译

1. 用 **Android Studio** 打开本工程根目录；
2. 等待 Gradle 同步（自动拉取 AGP 8.2.2 / Gradle 8.2）；
3. 连接手机，点击 **Run** 即可安装。
   > 本仓库不含编译好的 APK。你也可以自行生成后发布到 GitHub Releases / 自己的下载页。

## 四、使用步骤

1. 打开本应用 → 点击「开启无障碍服务」→ 在系统“无障碍”列表里找到“银盾”并开启开关；
2. 保持应用后台运行，并加入“电池优化白名单”与“自启动”名单；
3. 之后开屏广告与烦人弹窗会被自动跳过；打开「拦截统计」可查看并分享给家人。

## 五、规则自动更新（发布者必读）

规则更新源是工程内一个固定常量 `UpdateManager.DEFAULT_RULES_URL`，当前已指向本项目的 Gitee 仓库：

```java
// app/src/main/java/com/silvershield/app/UpdateManager.java
public static final String DEFAULT_RULES_URL =
    "https://gitee.com/stcbro/SilverShield/raw/master/app/src/main/assets/AllRules.json";
```

把 `app/src/main/assets/AllRules.json` 推送（或定时更新）到该地址，用户端会在联网时自动拉取合并（Gitee 默认分支为 `master`）。

**应用自身也支持自动升级**：App 会读取仓库根目录的 `version.json`（含 `versionCode / versionName / apkUrl / notes`），发现新版后自动下载 APK 并提示一键安装。发布新版时只需三步：① 递增 `app/build.gradle` 的 `versionCode`；② 同步更新 `version.json`；③ 把新 APK 传到 Gitee Releases（下载地址写进 `apkUrl`）。
完整发布步骤（推送 Gitee、零工具获取 APK）见 [部署指南.md](部署指南.md)。
维护规则请用脚本：

```bash
node tools/merge_rules.js   # 合并 A 层（社区）+ B 层（老人专属 tools/b_layer.json）→ 生成 assets/AllRules.json
```

## 六、如何补充规则（贡献指南见 CONTRIBUTING.md）

规则每条以「包名的 Java `hashCode`」为 key：

```json
{ "-173313837": "{\"popup_rules\":[{\"id\":\"+立即升级\",\"action\":\"+以后再说\"}],\"keywords\":[\"跳过\",\"关闭广告\"],\"package_name\":\"com.qihoo360.mobilesafe\"}" }
```

`popup_rules` 中 `id` 是触发文案/资源ID，`action` 是要点击的目标；前缀支持 `+`开头 / `-`结尾 / `=`全等 / 默认包含。

## 七、重要免责与立场声明

1. 本应用仅自动点击广告**自身提供**的“跳过 / 关闭”按钮，不破解、不屏蔽、不删除广告内容，不对任何 App 造成伤害。
2. **系统级锁屏广告（如手机出厂自带的锁屏信息流）不在普通应用权限范围内**，本软件无法处理。这类问题请向 **12321 / 12315** 或消费者协会等渠道反映，推动完善相关法规。
3. 本项目处于“厂商不爽、可能发律师函”的灰色地带，已采用开源社区化、去中心化方式降低单点风险；它的存在本身，正是为了**推动“一键关闭”成为法定义务**——届时此类工具可以体面退役。
